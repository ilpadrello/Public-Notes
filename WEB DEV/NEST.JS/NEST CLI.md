## Install the CLI 
`npm install -g @nestjs/cli`

## Commands

| COMMAND                       | DESCRIPTION                                                                                                            | NOTES |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ----- |
| `nest new your-project-name`  | Will initiate the project and create the basic files, will create also a folder with the same name as the project name |       |
| `nest generate module name`   | This will create a new module called name.module.ts inside a `name` new folder (if it doesn't exists yet)              |       |
| `nest generate controller hb` | This will generate a controller file, a controller spec file and import it from the root.+                             |       |
