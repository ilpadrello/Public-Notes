# Symmetric and Asymmetric Key
**Symmetric Key**: Is used to encrypt and decrypt, so both parties need to know the secrec key.

**Asymmetric Key**: There are two keys now!
- Public Key: can be shared
- Private Key: must remain secret
Those keys can be used in different ways based on the algorithm that you use:
- You can Encrypt a message using a public key and only the private key can decrypt the message
- You can verify a signature of something signed with a private key using a public keyu without beign able to sign using the public key.
*Asimmetric Keys* are a family of techniques using related public/private keys.
